# JavaScript Expense Tracker 💰

A responsive Expense Tracker application built using HTML, CSS, and JavaScript. It allows users to manage income and expenses, track monthly financial activity, and monitor their overall balance.

## ✨ Features

- Add income and expense transactions.
- Edit existing transactions.
- Delete individual transactions.
- Categorize transactions (Salary, Food, Travel, Shopping, Education, and Other).
- Filter transactions by income, expense, or all.
- Filter transactions by month and year.
- Search transactions by title.
- Sort transactions by amount (Low to High and High to Low).
- Calculate total income, expenses, and balance.
- Display monthly income, expenses, and savings.
- Save transaction data using browser LocalStorage.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding your income and expenses.
